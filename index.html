This application calculates weight and balance values for entry into the aircraft MCDU. Accurate aircraft data, configuration, and loading inputs are essential to those calculations.

The application does not connect to or control aircraft systems. The flight engineer must verify the inputs and calculated results, then enter and confirm the required values in the MCDU using the applicable aircraft procedures.

Before use, confirm that the application’s configuration data and reference documents are current and applicable to the aircraft.

OFFLINE USE AND RECOVERY
  1. Prepare the latest release: While connected, open Home and wait for Ready offline with the app and configuration versions shown above.
  2. After an update: If Home shows Preparing, keep the app connected, then close and reopen it to activate the verified release.
  3. Reversionary operation: On Home, select Use previous verified release. The app will remain marked REVERSIONARY VERSION.
  4. Return to current operation: Select Return to latest verified release from the reversionary banner.
